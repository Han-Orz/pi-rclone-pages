AgentDrive

A personal rclone setup for carrying out Google Drive file operations at the account owner’s direction.

What it does

AgentDrive runs on a private server and lets the owner’s AI agent, Pi, read, upload, download, and manage files in the owner’s Google Drive when instructed. It is for personal use and is not a public service.

How data is handled

Google Drive data is used for the file operations the owner requests. When Pi is asked to work with file content, relevant data may be sent to the model service or messaging platform used for that request.

Privacy

OAuth configuration and tokens are stored on the owner’s private server. Read the Privacy Policy for more detail about data access, storage, and sharing.

AgentDrive is an independent personal tool. It is not affiliated with or endorsed by Google or the rclone project.
